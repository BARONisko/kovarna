# Hlubinná kovárna (Deep Forge)

Mobile idle game – a dwarf smith forges random gear while the hero fights deeper and deeper under the mountain.

**Play:** https://baronisko.github.io/kovarna/

On iPhone: open the link in Safari or Chrome → Share → *Add to Home Screen*.
Progress is saved in your browser on your device.

This repository contains only the built game. Source code is private.
